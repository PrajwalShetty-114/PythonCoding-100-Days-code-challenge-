Python Built-in Functions Explained

These functions are very important in Python. They help you work faster and write cleaner code.

This document explains:

  • What each function does
  • Syntax
  • Different examples
  • Step-by-step explanation
  • Important notes

1. len()

What is len()?

len() returns the number of items inside an object.

It can work with:

  • strings
  • lists
  • tuples
  • dictionaries
  • sets

Syntax

len(object)

Example 1 — String Length

name = "Pajju"

print(len(name))
Output: 5

The string "Pajju" contains 5 characters.

Example 2 — List Length

numbers = [10, 20, 30, 40]

print(len(numbers))
Output: 4

Example 3 — Dictionary Length

student = {
    "name": "Ram",
    "age": 20,
    "marks": 95
}

print(len(student))
Output: 3
Spaces are also counted in strings. 
text = "Hello World"

print(len(text))
Output: 11

2. sum()

What is sum()?

sum() adds all numbers in an iterable.

Syntax

sum(iterable)

Example 1

numbers = [1, 2, 3, 4]

print(sum(numbers))
Output: 10

Example 2 — Starting Value

numbers = [1, 2, 3]

print(sum(numbers, 10))
Output: 16

3. type()

What is type()?

type() tells the datatype of a variable.

Syntax

type(variable)
    
x = 10

print(type(x))
Output: <class 'int'> 
name = "Python"

print(type(name))
Output: <class 'str'>

Common Datatypes

Value Type
10 int
10.5 float
"Hello" str
[1,2] list
(1,2) tuple
{"a":1} dict

4. max()

max() returns the largest value. 

numbers = [10, 50, 20]

print(max(numbers))
Output: 50 
print(max(5, 8, 2))
Output: 8 
print(max("apple"))
Output: p

5. min()

min() returns the smallest value. 

numbers = [5, 2, 9, 1]

print(min(numbers))
Output: 1

6. id()

id() returns the unique memory address of an object. 

x = 10

print(id(x))
Output will differ on every computer.

7. dir()

dir() shows all properties and methods available in an object. 

print(dir(str))
Output: ['capitalize', 'lower', 'upper', 'split']

8. help()

help() shows documentation about functions, classes, and modules. 

help(len)

9. sorted()

sorted() returns a sorted version of data. 

numbers = [4, 1, 3, 2]

print(sorted(numbers))
Output: [1, 2, 3, 4] 
print(sorted(numbers, reverse=True))
Output: [4, 3, 2, 1]

10. enumerate()

enumerate() adds index numbers while looping. 

fruits = ["apple", "banana", "mango"]

for index, fruit in enumerate(fruits):
    print(index, fruit)
0 apple
1 banana
2 mango

11. zip()

zip() combines multiple iterables together. 

names = ["Ram", "Sam"]
marks = [90, 80]

result = zip(names, marks)

print(list(result))
[('Ram', 90), ('Sam', 80)]

12. map()

map() applies a function to every item. 

numbers = [1, 2, 3, 4]

def square(x):
    return x * x

result = map(square, numbers)

print(list(result))
[1, 4, 9, 16]

13. filter()

filter() filters items based on condition. 

numbers = [1, 2, 3, 4, 5, 6]

def even(x):
    return x % 2 == 0

result = filter(even, numbers)

print(list(result))
[2, 4, 6]

14. any()

any() returns True if at least ONE value is true. 

numbers = [False, False, True]

print(any(numbers))
True

15. all()

all() returns True only if ALL values are true. 

numbers = [True, True, True]

print(all(numbers))
True
